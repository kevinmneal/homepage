# Companion artwork — v2

Generated October 15, 2026 with the built-in ImageGen tool, using `../../docs/assets/spadefoot.png` as the character reference. The three RGBA outputs are preserved unchanged at 1254 × 1254 pixels, with genuine transparency. Each contains a 4 × 4 grid of sixteen poses.

- [Typing atlas](assets/v2/typing.png): alternating paws and a blink at a laptop. Used for the Fortegra and watermarking behaviors.
- [Hop atlas](assets/v2/hop.png): crouch, takeoff, flight, landing, and settling. Frame zero is also the static companion.
- [Map atlas](assets/v2/map.png): opening a map, raising the magnifier, scanning, and lowering it.
- [Frame rectangles](assets/v2/frames.json): source rectangles for canvas drawing. Computed from alpha > 128 bounding boxes with two pixels of margin within each equal grid cell. This records metadata without modifying the PNGs. The renderer aligns each pose's feet to a shared baseline.

The reference was supplied to each call with `referenced_image_paths` and `transparent_background: true`. No CLI/API fallback was used. The output dimensions differ from the preferred dimensions in the prompts; the runtime uses the actual dimensions.

The exact generation prompts follow. Toad packing and token graphics are playful illustrations, independent of the scientific figure and supporting text in the dropdowns.

Show real in-between poses of paws and head, not duplicates. Same character, same camera, same scale, same laptop, same baseline and same placement in EVERY cell. Each cell has at least 12% transparent margin on every edge; nothing crosses cells. Whole body and laptop entirely visible within each cell. Warm ochre speckled spadefoot, creamy belly, dark eyes, modest calm expression, crisp economical pixel art, restrained outlines; should read at 140 pixels tall. Transparent background with genuine alpha, including all gaps between cells. No coffee, props other than laptop, chair, desk, floor, cast shadow, text, labels, grid lines, panels, scenery, or logos. Keep the toad morphology from the reference. This is an animation atlas, not a comic: exact regular grid and continuity matter most. Square output, preferably 1536 by 1536.
